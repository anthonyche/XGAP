# Controlled Interpretation input templates

Two explicitly selected phrase-template families cover the existing B01–B05
questions on the same five-node graph. Templates reuse the independently authored
input semantics of B01 and B04, with declared entity/age phrases and executable
hard constraints. They contain no expected answers, native queries or runtime
plan output. Old binding fixtures/gold remain frozen and are used independently
after Interpretation/execution for comparison.

This is controlled template intake, not a general NL parser. Template selection
is explicit caller configuration; no automatic intent classification or real
model quality is claimed. The manifest pins exact template bytes and logical
source assignments. B05 still uses its separately declared test clarification.

`replay/` contains two manually authored minimal development failures. Their
usage values are controlled examples, not measurements of an external service.
They remain available after temporary test directories are removed.
