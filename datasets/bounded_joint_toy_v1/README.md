# Portable bounded-joint toy

Synthetic financial development facts, copied from the previously validated
eight-node toy. `graph.ttl` and `control.ttl` are served as two local RDF sources.
`fixture.json` contains their mappings, one supported query template and its
independently hand-derived rows. These are development inputs, not evaluation.

The deterministic English template extracts the account ID from the question;
the public scope varies hop/time conventions. The simulated user separately owns
the complete intended query and must be queried before coverage is established.
No credentials, network, CWRU or private data directory is needed.
