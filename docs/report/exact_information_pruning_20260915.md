EXACT 原策略先询问模型，但其所有结果随后都读取同一权威绑定。当前固定绑定动作
的参数、可用性和权威结果不依赖模型提议；提议不会推进 EXACT 必需的验证状态。
新搜索入口跳过这些动作，保留全部权威结果与完整后续。模型仍列于原始可用工具中，
记录另列具体剪枝理由。通用 AND/OR solver、PERFORMANCE、固定外部前端均保持原逻辑。

## 结果与解释

使用上一轮已经选定的六个 development 输入：三个家族、native/RDF 两种表示，
只重查受影响的 EXACT。输入、profile、预算、估计器保持原 pin，禁止网络连接，
未重跑旧代码、PERFORMANCE 或外部方法。六个策略全部 strong，且三个最终 terminal
的 ID 集合与旧记录逐项相同。每个策略展开状态 **24→4**、生成动作 **7→1**，根动作
由模型改为权威读取，三个权威候选分支全部保留。

**状态减少不等于同比提速。** 旧实现已经复用相同绑定的物理计划；新实现仍须为
三个权威候选建立可行后续。上表每条件一次、不同时间运行，部分还变慢，不能给出
总体 planning 加速结论。确定的收益是删除不产生权威证据的模型步骤，并缩小搜索树。
这六次仅规划，模型/权威/源/最终计划执行均为零，不能当作六题答案正确。

进程内小图执行另验证两个不同权威回答：均得到预期的正确行，只调用一次权威工具、
零模型、一个最终联邦计划。PERFORMANCE 仍实际调用受控模型并使用授权的未验证
绑定；固定外部 EXACT 前端仍按声明顺序调用模型再取权威回答。这里的模型是测试
工具，不是新 live LLM 测量，也没有更改外部基线来优化其表现。

## 有界性与验收

[决策与证明范围](../decisions/exact_information_pruning_v1.md)：在当前固定独立绑定
动作域，将状态投影为已验证绑定、证据和已尝试权威动作；非权威提议为不改变投影
的步骤。删除这些步骤保持可行策略及保留动作的全结果后续。已知非负分数/资源下，
删除不增加所保留子策略的最坏路径分数与资源；未知分数不产生数值保证。仍无
全局最优、搜索完备、答案误差或近似比声明。额外预处理为 O(M)，动作最多 128 个，
后续沿用原有有界搜索。规则不适用于会改变后续参数或工具能力的一般信息动作。
