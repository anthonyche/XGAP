## 本轮完成了什么

### 1. 修复同一计划内的重复读取

代码 `24c34997846bca7c27154110e6eeb98351e32b4e`：编译器证明两个完整 Match
仅输出别名不同、源和快照相同时，执行一次原始查询，再为其他消费者映射列名。
不增加低层语义，不试跑多个计划，不跨请求缓存，不改变谓词或结果多重性。
受约束/限量/绑定查询及无法证明等价的读取保守排除。
两种模式和候选计划都在成本估计前应用同一优化。

34 项不重复定向测试通过，覆盖独立 RDF 边对答案、并行边、自环、空值、源身份、
不同谓词、修改后的解码器、SPARQL 内部别名冲突、失败传播等边界。

真实 Neo4j+Fuseki 验证复用旧 pilot 的 P01（空答案）和 P13（唯一非空答案），
每题运行两种模式，共 **4 次执行、0 次模型调用、0 次重试，全部答案正确**。
这两题是显式开发诊断选择，不构成新正式样本；旧结果完整保留。

### 2. 扩展有界工作负载构造和独立参考

代码 `c3ec6f5` 增加三种结构：时间可达路径、账户转账聚合、公司账户转账聚合。
每种 16 个候选，4 个显式语义坐标、总权重 6；固定业务 ID、方向等不能放松。
提供自然语言问题、候选范围、独立原始 CSV 参考计算；路径仍限递增无环 1–2 跳，
聚合限已支持的 sum/count。模型提议不持有权威意图。

WHERE 坐标增加公开的属性/操作符定位：模型调换合取条件顺序时仍修改正确字段；
缺失、多个匹配、重叠位置或多个 proposal 位置不一致时拒绝，不静默修复含义。
未使用新定位器的旧策略序列化保持不变。

27 项定向测试通过，包含新构造、定位边界、CSV 参考和既有 bounded-joint/sampling
契约；没有重复跑全库回归。独立小数据检查保留相同值的并行转账、账户所有权，
并区分时间边界、严格递增、无环及结果去重。

另完成一次原始 SF0.1 的**离线构造检查**：每种取字典序首个对应类型 ID、全快照
时间窗、全部 16 个意图；选择文件先封存，再计算参考。48/48 候选可编译且参考生成
成功；非空参考分别 8/16、8/16、0/16。所有结果保留，不因为空重抽。
这些是同一锚点下的候选，**不是 48 个独立问题，也未跑原生后端或 LLM**。
尚未发布新 24 题批次或冻结正式工作负载；不能以这些参考计数作为系统正确率。

## 当前已有实验能说明什么

之前已封存 [FinBench 首轮 pilot](chapter7_pilot_20260920.md)：24 个问题、48 个模式单元，
47 次答案正确、1 次模型超时，零重试。但 23/24 参考为空、仅一个结构模板，不能据此
主张强答案质量。受控 Performance 少一次澄清，端到端时间仍相近，说明当前执行费用
掩盖了信息获取收益；本轮优化同时降低两种模式的执行负担。

目前可报告真实联邦闭环、可追溯失败、减少澄清的机制和重复读取优化。
尚不能报告三数据集整体优势、SOTA 胜出、完整 cost–discrepancy–coverage frontier
或 E1–E20 已完成。结构 query loss 也仍不等于输出答案误差保证。
