## 已实现

- 普通one-shot入口接纳冻结的RDF实例工作估计器；其原权重、源身份检查和估计选单个
  计划规则不变。此前固定语义入口已接受该类型，普通入口缺失的类型准入现已补齐。
- 共享外部前端使用冻结precision信息配置：同一模型、compact语法、catalog，最多
  K3解释。grounding后按质量proxy及稳定ID选择一个解释，只编译该解释一次；编译
  失败不换候选，没有cost选择、当前题probe或外部执行结果反馈。
- 全局编译器直接接已grounded的语义DAG，没有题号/家族分发或gold-query替换。
  输出一条无SERVICE/端点地址的SELECT，由原外部引擎负责执行全部查询。合法的纯
  重命名、过滤、连接层合并；投影去重、union和聚合边界保留，变量作用域独立。
- 明确限于≤64语义operator、128KiB输入、4096展开关系和1MiB查询；Match及已降低的
  1..3hop路径、Filter/Join/Union/Project、SUM/COUNT和最终OrderLimit。未降低Traverse、
  Align、中间排序、MIN/MAX及异构RDF项排序不在本版桥接范围，拒绝时归为我们的
  编译边界，不伪装原生baseline不支持。数值沿用冻结三位小数评价口径。
- 共同外层入口支持NL-only请求、模型/编译/执行费用、托管方法和源资源、失败后停止
  自有进程组，以及封存后的独立评分。中断的未知模型费用不变成0。逐次真实推理
  独立收费，没有复用一份模型响应冒充两种系统的真实延迟。

raw scorer按“执行失败”规则留下EM/F1=0，记录不改写；**它是验证预算截断的开发
记录，不能作为FedX原生答案质量的对照点**。为确认已生成查询本身，仅对该已保存

诊断时间也不是FedX时延。没有重跑模型或baseline，没有按结果优化其查询/算法。

单元；没有重复已成功XGAP单元、改作者JAR或重建baseline。首次启动失败及未测量的
失败准备时间原样保留。已测成功服务准备分别1761.716ms、1967.466ms，单列为离线。

全部8个自有服务进程均终止；原profile、请求、reference与两源文件校验不变。
