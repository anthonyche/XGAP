## 结果告诉我们的事情

1. **三个结构的真实链路通过。** 时间递增路径、出向转账聚合、公司 ownership 聚合均从
   当前入口运行在真实 Neo4j+Fuseki。Exact 的 24 次答案全部匹配独立 CSV 参考。
   此前 tiny NL 的六次失败仍保留；前端契约修复后的本批结果单独记录。
2. **存在获取成本与答案的权衡，但没有速度收益。** 受控 Performance 省去澄清，
   其中 C17 相比 Exact 的空答案返回一行，EM/F1 都为 0。实测结构 loss=1/3 ≤ ε=1/2，
   不属于证书违规。该组平均执行时间 11.82 s，对照 Exact 10.87 s；平均响应正文
   34.12 MiB，对照 31.17 MiB。省一次本地模拟澄清没有抵消后端工作，不能宣称更快。
3. **完全未知的 NL 输入目前两模式行为相同。** 每题都澄清一次、调用模型一次，
   两者平均后端响应均为 31.17 MiB；这批不存在 LLM/probe 节省证据。
4. **答案质量评价仍受空参考限制。** 21/24 题参考为空：路径非空 2/8、出向聚合 1/8、
   公司聚合 0/8。高 EM 不能外推为复杂非空查询质量优势。按用户批准引入源结构活跃锚点
   框，与全 ID 框分别报告；不按这些结果替换题目。

配对 Performance−Exact 耗时标准差：NL 2.832 s，受控 0.964 s。只有 12 对/轨道，
且模板共用，因此不作总体优越性或未见模板泛化推断。正式样本/重复在新结果打开前冻结。
