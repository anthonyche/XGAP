## 不得混淆的实验规模

[原计划](../ch6_experiment_plan_20260922.md)的初始目标是每域每 W 层 200 道
query–intent case，即每域 800、三个域共 2,400 道基础题，之后另计方法和重复。
这不是已完成的样本，也不是已完成的功效分析；缩小最终范围需要明确说明并由用户决定。

当前冻结的总体题库为 D1 56、D2 56、D3 64，共 176 道基础题。
当前配方中的 2,400 是这些题按支持的方法和三次重复展开后的方法请求数；
4,356 则还包含因子和机制实验请求。两者均不能代替原计划的 2,400 道基础题。

当前题库来自自建的有界核心模板。LC-QuAD 的结构提取材料仍需领域实例化、
编译与独立参考准入，尚未接成这批正式题库的完整来源链。
不能将本批称为官方 SNB/FinBench query suite，或已经完整接通的 benchmark-derived workload。
部分名为 test 的病例已用于工程诊断和修复；保留其原 ID 与全部证据，但不能称为
从未被开发使用的最终测试集。
