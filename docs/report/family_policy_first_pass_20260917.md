## 当前结论及下一步

1. 有限家族机制已可真实评价：提前终止能节省信息，并在受限预算下增加返回答案比例；
   有选择的信息搜索在至少一个紧预算实例上优于固定序。
2. 不能claim总体更快或整体搜索优越：根停止场景简单规则等效，部分确认搜索CPU更高；
   时间重复未完成、源缓存仍有影响，不能从单次观测计算显著性或论文总体speedup。
3. ε与答案质量的关系是当前关键理论/测量边界；放宽ε可能大幅失去答案。这里没有按
   结果调整epsilon、候选、隐藏真值、估计器或对照策略。
4. 下个工程门应先做小图记录存储共享/无损压缩、预算原因透传与每题容量预检，保留完整
   证据及源bytes真实计费。完成后另行冻结继续方案，只覆盖此前未运行部分并明确不同
   记录实现的时间不可直接合并；不重跑已失败/已回答题来改善分数。
5. 补齐hard/cheap负对照和预定顺序证据后再决定复杂搜索是否值得保留。开放NL覆盖、
   模型/probe按需策略、外部SOTA有效共同支持与scalability依然不是本轮完成项。
