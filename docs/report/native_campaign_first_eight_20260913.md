## What this changes next

The implementation path is connected. The captured Cypher shows a concrete
transport inefficiency: `RETURN DISTINCT e1 AS entity, source, target` returns
whole native property objects. In group 0, the two unrestricted transfer-edge
reads each returned 106,715,911 bytes. Canonical binding normalization subsequently
extracts identity fields; requested scalar attributes are already projected
separately. This is evidence for examining compact identity projection, not proof
that it alone explains every memory/latency cost or that the estimator ranks
plans incorrectly. No source/estimator/model change was made during evaluation.

Next engineering gate: validate identity-only transport on tiny data, preserving
parallel-edge identities, scalar properties, missing-identity behavior and
cross-source joins. Keep all current results and do not raise limits or repeat
these failed full-data queries to debug. A later implementation version must be
explicitly recorded; its times cannot be silently pooled with this prefix.
Baselines remain unchanged. Native fixed scheduling next starts at group index 8;
native NL has a frozen schedule but is unstarted. RDF fixed is next at group 5,
RDF NL at group 1. Nonempty real answers, overall NL effectiveness, FedShop and
the remaining approved evaluation are still required.
