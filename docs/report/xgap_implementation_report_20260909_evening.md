新增只读验收模块，重新计算每次 inline grounding 转换、候选反馈和修复请求，
检查原始响应、调用顺序、token 检查记录、传输记录与最终消费的响应是否一致。
此前 D197 的诊断回放只检查成功的最后一次转换；D198 同时覆盖前面的失败和修复。
更改派生内容后重新计算哈希、删掉首次失败、替换修复提示，都会被拒绝。

失败不会被丢弃：生成/修复超时、token 拒绝、修复仍失败，也可以作为真实失败证据
通过一致性验收。通过验收不等于回答正确。整场实验的独立接纳还需要绑定冻结的
问题集合、catalog、producer commit、运行环境、tokenizer 与指标计算。
