# Practical information cost basis

## Material Passport

2026-09-15; bounded development measurement, not paper evaluation or a mode
release. RQ: which actual tool costs should inform the information policy?
X: fixed local binding authority versus the already configured remote proposal.
Y: invocation wall time, reported model/remote calls and tokens, result status,
and proposed binding agreement with the separately acquired annotation.

Use exactly the three previously selected native development questions (one per
family). RDF has the same questions and candidate provider; do not repeat calls
for that representation. No graph query, physical candidate execution, answer
reference read, training, catalog build, server operation or baseline run.
No changes to templates, model prompt, sampling, candidate set or authority.

Each question receives at most one proposal and one local authority call. Tool
order is model/authority, authority/model, model/authority, fixed before results.
The second tool receives only its own prebuilt arguments, never the first result.
Maximum three model attempts, each max512 output tokens and45-second timeout;
4096-token reservation per call is not a provider-enforced total-token guarantee.
Stop subsequent model attempts after the first non-success, preserving unattempted
slots and all failures. No retries or repair. Three authority calls remain local.

Capture scoped intents/results, safe provider metadata, request/profile pins,
code/driver versions and actual durations. Credentials enter memory through the
existing environment name or a non-echoing input; never store them in artifacts.
The driver has a200-second hard deadline around preparation/measurement.

If all three attempts of a tool succeed, report median/min/max invocation wall
time as a small local development sample. A failed or missing attempt prevents
a complete sample estimate; keep the estimate null and disclose censoring.
No numeric confidence bound, significance or general latency-calibration claim.
Unknown usage remains null. Model agreement is slot agreement on these exposed
development inputs, not query answer accuracy or evaluation-set generalization.

Publication requires provenance for any subsequent numeric estimate or relative
order. These samples alone do not change a profile. Do not inject human delay,
reorder baseline sequences, or force PERFORMANCE to beat a cheaper authority.
The already approved bounded information/physical cost research authorizes this
measurement; final scope/dataset priority and the18-figure discussion stay intact.

Allowed files: this contract, a bounded measurement driver/protocol, receipts and
current status documents. Acceptance: zero-call preflight, at most the declared
tool invocations, exact input pins, immutable original captures, no source calls.
Use existing adapters; no unchanged native gate or broad regression suite.
