## Factor-to-measure mapping for the revised Chapter 7

This translates the accepted research scope to required measurements; it does not
choose favorable numerical settings or replace the user's final figure design.

|Question|x-factor|y-factor|Methods/controls|
|---|---|---|---|
|Overall utility|Dataset and sampling frame|End-to-end latency/work, answer EM/F1 and coverage|Unified, sequential, admitted faithful external methods on the same panel|
|Joint information value|Uncertainty/support and declared acquisition price|Actual clarification/probe calls, total cost, completion|Shared s0/data/tool outcomes; prices fixed before results|
|Planning overhead|Fixed D; family, plan-pool and action sizes|Planner CPU/wall, certificate time, expanded states, peak RSS|Same inputs/budgets; record guard/fallback rate|
|Contract sensitivity|Lambda/epsilon|Measured query loss, answer quality/coverage, actual cost|One algorithm; no assumed two-mode speed hierarchy|
|Estimator usefulness|Frozen rank/work estimator and held-out error|Selected execution cost/regret where independently measurable|No current-query trial oracle inside online method|
|Scalability|Data size and actual source/partition count|Latency, transfer/calls, memory and completion|Actual mapping/semantics admission required first|
|Component contribution|Predeclared feature toggles|Same outcome/resource metrics|Only after main comparison; no blanket exploratory ablation loop|

Offline catalog/summary/model training costs are one-time preparation and must be
reported separately, with declared amortization if desired. Initialization and
online acquisition are measured separately but count toward NL end-to-end totals.
Do not sum overlapping certificate/planner times or compare controlled timings
with external NL whole-request timings as if they were the same task.

## Explicit release blockers

1. Original ARUQULA+FedUP has no successful model→lookup/source invocation in the
   current composition; latest failure is a remote model timeout, not a scored
   database answer. Determine supported transport/model execution without tuning
   author reasoning, prompts, output repair or decoding for result quality.
2. Tiny native/RDF admission does not admit all Freebase/FedShop mappings or
   real source sharding. Preserve supported/unsupported/setup-failed distinctions.
3. No final revised figure matrix, dataset cell grid or whole-study budget is
   frozen. A missing metric or failed method must remain visible rather than
   replaced with invented values, easy questions or a different method label.

Once these gates are resolved or explicitly scoped in a new release, the next
step is the new frozen pilot/formal manifest. Do not auto-resume old attempts or
silently repurpose the old paused application Goal.

Transport diagnosis update: the old observer bypassed the system HTTP proxy,
while the working compact client used it. Explicit proxy support now preserves
original request bytes; a new tiny admission is needed. The old timeout remains
harness/network evidence, not an intrinsic method performance result.
