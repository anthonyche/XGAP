# T4: bounded NL, authority, joint costs and reproducible storage

User-authorized engineering milestone, 2026-09-17. No new evaluation campaign.

## Contract

The canonical entry constructs candidates from a supported compact-query proposal
and frozen finite slot domains. Model output is a proposal, never completeness or
intent authority. The private simulated user holds a question-bound complete query,
independent of the candidate release. A metered scope-confirmation action checks
that this user's intent is contained in the proposed set and reveals only yes/no.
Only a positive reply activates the certificate. Out-of-scope proposals fail
explicitly; there is no hidden gold repair or confidence-based coverage claim.
Further full/scoped clarification is metered and preserves the existing strong
contract. Scope confirmation is charged in both modes, not credited as a saving.

The frozen scope policy chooses Cartesian coordinate expansion or `proposals_only`
Top-K support, without inventing all coordinate combinations. Both paths require
the same paid containment reply. Constant coordinates become fixed skeleton fields.

Scope is the existing compact language and declared finite slot domains, at most
64 complete candidates/32 coordinates. Product cardinality is checked before
generation, never truncated. Explicit fixed fields remain hard. Entity grounding
must use declared IDs/domains; unsupported mentions are not silently guessed.

## Cost and search

One frozen additive cost profile prices information and estimated final execution
in common declared work units. They are not claimed to be measured milliseconds.
Physical strategies come from the existing polynomial one-source neighborhood,
including supported binding reductions. No actual current-query probes, fit or
multi-plan execution is permitted. Unknown evidence and heuristic assumptions
remain visible. Calibration/ranking can later replace coefficients without
changing the safety contract.

Check terminal eligibility first and retain a certified incumbent. Compare its
estimated execution cost with complete information-action continuations; an
eligible terminal need not trigger further acquisition when the estimated
alternative cannot improve it. All selected AND outcomes require feasible plans.
Candidate preparation/certificate work is cached per request; the runtime follows
one observed branch and executes one final plan. Shared safety checks are reused.
Bounded search is heuristic: retain the best discovered feasible policy, no global
optimality or constant approximation claim. Document input/candidate/state/action
limits and the polynomial bound in the final implementation map.

## Storage and resource gate

Stream lossless gzip evidence with stored and logical hashes/byte counts. Keep
legacy raw records readable. Compression must not alter transmitted source bytes,
answers, multiplicity, ordering or independent replay. Corruption/oversize reads
fail closed. Avoid materializing an additional full JSON string during recording.
Study-wide guard reasons take precedence over shutdown-induced transport errors;
retain the latter as secondary evidence. Do not change sealed T3 artifacts.

  hard constraints, zero epsilon, one-final-execution, cost-sensitive choices and
  all-outcome feasibility. Use tiny independently answerable graph inputs.
- Storage replay equivalence, tamper/bound rejection, meaningful compression and
