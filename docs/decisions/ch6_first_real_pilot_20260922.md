# 第六章首批真实结果：冻结协议

用户最新要求继续取得实验结果。本批优先使用已装载的真实 FinBench SF0.1，
不等待 D1/D2 的完整装载，也不把旧双模式实验改名。发布脚本
`scripts/release_ch6_finbench_first.py` 在任何方法调用前写入源码、快照、配置、
抽样和预算的哈希。原始数据、私有意图及模型内容只保存在本地。

- 6 个 case：路径可达、账户转账聚合、公司所持账户转账聚合各 2 个。
  各族包含均匀 ID 和源图活跃 ID 两层，分别报告。固定 seed，取历史保留的 pilot
  anchor fold；不读取答案或方法输出选题。全快照时间范围，固定上界闭区间。
- 每题 3 个二值未定字段、8 个合法解释、等权 loss、epsilon=1/3。公开问题说明全部
  固定条件；模拟用户保存独立抽出的私有意图。不是 LC-QuAD 衍生正式集或 W1–W4 全覆盖。
- NL：XGAP、Two-stage、LLM-direct 各 6 次，同一 Qwen 服务、schema、prompt 和
  4096 输出 token 上限，最多 18 个生成调用、不自动修补或重试。
- Controlled：前两种方法各 6 次。仅该轨道给出公开冻结候选，不调用模型；不能称
  NL 端到端耗时，也不把其 12 次执行算成新增独立问题。
- D=2，H=12，K=4；每次可选搜索 1500 ms；最大 9 次绑定、32 次后端动作调用。
  两阶段共享资格、完成保护与物理组件。允许双字段澄清，与全字段/单字段动作同属
  预先公开动作集合。无新统计 probe target，因此本批不检验 probe 的价值。
- 30 个 cell 最多执行 30 个最终计划；模型输出总上限 73728 token，输入和实际
  token 独立记录。外层总时限 3600 s、每 cell 120 s、后端请求 30 s。
  worker RSS 1 GiB、sources 2 GiB、产物 2 GiB、磁盘保留 6 GiB。
- 新服务副本无查询预热，成功后复用；失败即关闭，下一题开新副本。按题轮转方法顺序，
  不做重复取均值，不宣称严格缓存控制的加速结果。服务启动/离线装载不混入每题延迟。
- LLM-direct 的 worker 不接收 oracle、scope 或 controlled artifact；一次 proposal
  接相同物理规划。无意图资格证书；其查询 discrepancy 当前记不可用，不伪造 certificate。
  三者共同报告答案 EM、行 multiset F1、回答率、实际时间和调用；失败保留分母。
- 初步实际工作量分数使用共同权重：绑定调用 1，披露字段 .25，后端 HTTP attempt 1，
  planner CPU ms .01。初始化/LLM 单列，单位是声明的工作量单位，非美元/实际延迟。
  该分数不使用任何方法自己的计划耗时预测；缺失资源记 null。

本批仅验证新方法在真实规模事实上的表现和下一轮瓶颈，不做显著性、泛化或 SOTA
优越性声明。模板与开发共享，样本量不足；需要据此完成独立模板族、三域接口和正式
预算后才扩展。外部 ARUQULA+FedUP 保留已封存的 VALUES/OpTable 不支持记录，
不改作者算法或逐题优化。
