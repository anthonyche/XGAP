# Disjoint canonical RDF facts with local metadata v2

The first common trial exposed 24 duplicated type/identity triples in our tiny
two-source representation. An unresolved global SELECT produced128-times totals
under FedX while the RDF set union and independent financial reference gave66/9.
The old run stays preserved as a representation-confounded diagnostic, not a
planner advantage or a reason to modify the baseline.

This milestone corrects our shared representation only. Allowed files: an offline
v2 derivative publisher, relevant tiny checks/harness and evidence. No baseline
code/query/answer changes, new financial facts, cohort changes, fitting or prompt
tuning. Do not rerun FedUP's unchanged aggregation failure or old readiness gates.

Keep all graph-source bytes and all real control attributes unchanged. In the
control source, move duplicate type objects, sourceId and xgap_id predicates into
a dedicated control-metadata vocabulary. Preserve subjects and literal bytes.
They are local aliases for the same type/business identity, not extra transactions.
Per-instance XGAP compiler mappings translate the existing logical class/id fields
to these aliases. The global public mapping/SELECT stays canonical and unchanged.
Auxiliary triples are visible to every method, explicitly declared and included
in load/summary/storage/traffic costs; no method receives private extra data.

The resulting graph/control triple sets are disjoint. Removing only auxiliary
control metadata from their union yields exactly the old RDF set union: the
canonical type/identity facts already remain on graph, and all financial/control
facts and parallel-edge resources are unchanged. This supports the same fixed
query semantics without source-overlap bag multiplication. It does not repair
an original method's missing aggregation/order or guarantee faster execution.

Publish a new exclusive directory; preserve old files, profiles, weights, catalog
and results. Streaming rewriting accepts only the pinned v1 serializer and changes
only designated predicate/type tokens, never matching words inside literal values.
Graph is referenced by an immutable verified file pin, not copied or hardlinked.
Serving records identify the actual graph/control files, their versions and this
mapping. Updated control serialized-size work statistics remain uncalibrated; the
parent training artifact and coefficients remain byte-for-byte equal.

Acceptance: tiny no-overlap and canonical-union equality; all three unchanged
public financial queries match their independent answers on the new union;
compiler metadata classes/id aliases and frozen model/profile consistency; literal
preservation and invalid input rejection. Then one common live trial each for
XGAP-RDF and the unchanged FedX on the same exposed meaning to verify the corrected
boundary. FedUP's known unsupported aggregate is not rerun. No large-data queries.
