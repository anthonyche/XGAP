## 应提前识别的失败类型

- `bind` 限制输入身份键，不限制键对应的边数；偏斜入度可使响应超过字节上限。
- 最终 LIMIT 限制答案数量，不能据此推断前面的连接、DISTINCT、排序或源扫描有界。
- 单源完整下推规则不能直接覆盖带外部属性的查询；同一图形跨源后可能切回协调端物化。
- 源进程 RSS、引擎堆/页缓存、事务内存和 HTTP 响应上限属于不同层；通过一个不是全部通过。
- 相对代价估计用于排序。它既不能创造不存在的策略，也不是预算内成功的证明。

前述大类属于可预见的结构风险。准确的触发基数、引擎物理计划、缓存/磁盘状态仍需真实
执行或有界 EXPLAIN 验证。此前小图重点保证了语义等价，却没有充分覆盖高扇出与跨源
算子组合；资源 guards 多在执行时停止损害，没有替代规划前风险检查。
