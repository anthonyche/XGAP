# Tiny split-source ordinary-NL gate

This development milestone closes a concrete effectiveness/integration gap:
the accepted new one-shot runs used either replicated facts or a declared program.
It is not a new accuracy/efficiency comparison or a fitting campaign.

Create four people in a Neo4j-only profiles source and three directed KNOWS edges
in a Fuseki-only relations source. Fuseki has identity stubs, not ages or Person
types; Neo4j has no KNOWS edges. Both use a shared fixture identity namespace.
A frozen local catalog covers entity/type/relation names and a bounded numeric
literal vocabulary; neither the answer nor a semantic program is model context.
One NL-only request asks for Nora's direct known people aged at least 30 and the
edge identity. Its request has no predeclared operator IDs, structured constraints
or requested_output structure. Permitted context supplies logical source schemas.
Independent gold program/targets/rows are separate, with answer evaluation only
after sealing inference. Deterministic compilation checks remain separate from
the single actual model call.

Reuse the accepted v2 training weights. A separately frozen deployment artifact
embeds the unchanged parent model and binds new offline source statistics, exact
identities and preparation provenance. No fitting or label collection occurs.
Backend feature names must match, all training provenance remains attached, and
runtime source/snapshot checks remain strict. Predictions explicitly mark domain
transfer and lack of calibration; numeric source statistics can leave the old
training range. Never change parent training statistics to pretend it was trained
on this fixture. Offline binding is O(B+d+N) in the already bounded artifact size;
prediction preserves polynomial work plus linear deployment-provenance handling.
No improved rank or actual-time error bound is assumed.

Allowed changes: versioned estimator deployment adapter, its ordinary-entry loader,
new independent tiny fixture, one bounded harness, focused new-risk checks/docs.
No old artifacts/data/gold edits, current-query probes, repeated training, retries,
large-data or baseline/ablation runs. Remote3804210 remains user-managed.

rejected; actual source separation and independently specified target semantics;
