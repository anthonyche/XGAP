# XGAP Current Roadmap

2026-09-16。已恢复NL首版工程/评价。当前时段及授权见[Goal](goal.md)，总体研究目标尚未完成。

## 当前优先级：先可评价

1. 完成单次真实NL到当前strong planner的接线；不伪造模型结构权威。
2. 小图模块检查、一次真实八节点双后端门，通过后冻结配置和首批12题。
3. 首批SF0.1真实模型/native/RDF结果，记录失败、正确率和完整成本。
4. 依据首版结果再讨论优化和完整48题/多数据集实验；不预先追求PERFORMANCE必胜。

本次用户授权和界限见[NL契约](decisions/nl_conditional_strong_v1.md)。

## 已通的有界骨架

- P-S1：有限深AND/OR strong policy，先保留完整可行策略，再做有界估计改进。
- P-S2：冻结catalog、可选LLM、按需绑定权威、普通profile/record入口与真实双后端链。
- P-S3：协调器/首跳/逐跳候选，完整读取共享、必要过滤、准备和预算优化。
- 共同研究入口：独立study、固定信息外部前端、监督、observer、评分与不可覆写journal。

具体实现与证据见[当前状态](status.md)及[首轮报告](report/partial_strong_first_pass_20260915.md)。
“已实现”不等于任意语义已验证，也不等于有模式优势或scalability结论。

## 本轮验收及待讨论候选（不自动执行）

1. 冻结FinBench首轮已封存，384/384均有终态与评分，源/模型费用已核对；已验收讨论并恢复本轮NL首版。保留原始异常、预算截断、
   空/非空分层和观测范围；不将失败时间用于速度比，不混旧版本结果。
2. 回到toy开发：修正模型usage跨摘要接口丢失；实现经编译器验证的别名读取共享，保留
   每个消费者字段、typed过滤、重复边与聚合语义。只跑新风险和受影响小图门。
3. 检验已存在RDF equality-key统计的接线与估计特征。key数量界限不等于关系结果基数；
   先用小反例验证扇出区分能力，再判断是否需要新的离线统计和训练。仅用原training
   划分拟合/排序，不将当前evaluation时间变成训练数据。
4. 在全strong seed完成以后设计便宜的PERFORMANCE物理改进，保留fallback和多项式
   输入/候选界限；不直接打开整个昂贵搜索域，不强制某种策略胜出。
5. 按已批准优先级推进bounded FedShop。先验证作者原查询和XGAP共同支持语义，再冻结
   有界子集/分区/同事实权限。所有12个作者模板保留coverage记录；不按结果挑子集，
   不为baseline补语义或改算法。原48题FinBench结果保留为当前版本证据。
6. 核心改动通过小图后，独立冻结下一版模式/估计器/实验协议，按[18图契约](research_contract_audit_20260915.md)
   执行主效率/效果/规模结果，消融最后。新旧版本与曝光必须分开。用户推进d之后再接
   正式误差契约；无epsilon主张的工作不因此停止。

## 排除的工作

不建设无限语义的通用产品；不把GrailQA当开发环境；不自动重提远端作业；不优化baseline
结果；不重复无新风险的回归或用评价赢家调整估计分数。
